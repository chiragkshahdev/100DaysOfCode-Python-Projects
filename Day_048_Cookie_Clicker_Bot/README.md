# Day 48 - Cookie Clicker Bot (No Selenium, No Pip)

An auto-clicker bot for Cookie Clicker that uses only Python's built-in libraries. No external installation needed.

## Features
- No Selenium
- No Pip Install
- No Chrome Driver
- Uses Windows built-in `ctypes` library for mouse clicks
- Clicks 30 times per second
- Works on any website / game

## Requirements
- Python 3 (Windows)
- Google Chrome / Any Browser
- No extra libraries needed

## How To Use

### Step 1: Open The Game
Open Cookie Clicker in your browser:
https://orteil.dashnet.org/cookieclicker/

Select Language: English

### Step 2: Run The Bot
```bash
py main.py
