# Day 49 - LinkedIn Job Finder (No Selenium)

A simple and safe tool to find LinkedIn jobs using only Python Standard Library.

No Selenium, No Pip Install, No Login Required, No Auto Apply.

## Features
- Uses only Python built-in libraries: urllib, re, csv, webbrowser
- Searches public LinkedIn jobs without login
- Saves Job Title, Company and Link to jobs.csv
- Opens LinkedIn in browser for manual apply
- 100% Safe - No account ban risk

## Requirements
- Python 3
- Internet Connection
- No extra library needed

1. Run the program:

py main.py
