# Day 01 - Band Name Generator

This is Day 1 Project of the 100 Days of Code: Python Bootcamp.

## 📌 Description
A simple beginner program that generates a band name based on user inputs.

The program asks two questions:
1. The name of the city you grew up in
2. Your pet's name

And then combines them to suggest a band name.

## 🧠 Concepts Used
- `print()` function
- `input()` function
- Variables
- String concatenation
- f-strings

## ▶️ How to Run
```bash
python main.py
