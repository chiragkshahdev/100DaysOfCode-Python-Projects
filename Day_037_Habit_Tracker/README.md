# Day 37 - Habit Tracker

A Habit Tracker App using Pixela API. It creates a GitHub-like green graph for your daily habits.

## Features
- Create Pixela User
- Create Habit Graph (Coding, Workout, Reading)
- Add Today's Habit (Pixel)
- Update Habit for any date
- Delete Habit for any date
- View Graph in Browser

## API Used
Pixela - https://pixe.la
Free, No API Key Required. You create your own Token.

## How to Run
1. Install requests:
   pip install requests

2. Change USERNAME and TOKEN in main.py to your unique values

3. Run the app:
   python main.py

4. First time run:
   - Choose 1 to Create User
   - Choose 2 to Create Graph

5. Daily use:
   - Choose 3 and enter hours

## View Your Graph
https://pixe.la/v1/users/YOUR_USERNAME/graphs/graph1.html
