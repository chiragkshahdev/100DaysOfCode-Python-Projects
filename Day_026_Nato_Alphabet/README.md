# Day 26 - NATO Alphabet Project

This project converts any word into NATO phonetic alphabet using Python & Pandas.

### ✨ Features
- Reads NATO alphabet from CSV
- Uses Dictionary Comprehension
- List Comprehension to convert word
- Error handling for non-letters

### 🛠️ Concepts Used
- `pandas` - CSV reading
- `iterrows()` - Loop through DataFrame
- Dictionary & List Comprehension
- Exception handling (try/except)
- Recursion

### ▶️ How to Run
```bash
pip install pandas
python main.py
