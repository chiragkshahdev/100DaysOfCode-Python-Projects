# Day 14 - Higher Lower Game

A game where you guess who has more Instagram followers.

### 🎮 How to Play
1. You will see 2 personalities - A and B
2. Guess who has more followers: Type `A` or `B`
3. If correct, score +1 and continue
4. If wrong, game over!

### 🧠 Concepts Used
- `random.choice()` - to get random data
- Dictionaries & List of dictionaries
- Functions with return
- While loop for game loop
- `os.system('clear')` to clear screen

### 📁 Files
- `main.py` - Main game logic

### ▶️ Run
```bash
python main.py
