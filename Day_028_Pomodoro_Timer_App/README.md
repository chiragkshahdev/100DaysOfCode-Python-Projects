# Day 28 - Pomodoro Timer App - Python

A beautiful and productive Pomodoro Timer built with Tkinter. Part of 100 Days of Python Challenge.

## ⏱️ What is Pomodoro?

The Pomodoro Technique is a time management method:
- Work for 25 mins → Short Break 5 mins
- Repeat 4 times → Long Break 15 mins
- Stay focused, avoid burnout!

## ✨ Features

- **Visual Timer** - Tomato UI with countdown
- **Auto Cycle** - Work → Short Break → Long Break automatically
- **Progress Bar** - Shows session progress
- **Checkmarks ✔** - Tracks completed work sessions
- **Custom Time** - Set your own Work/Short/Long durations
- **Sound Alert** - Beep on session end
- **Start / Reset** controls

## 🛠️ Tech Stack

- Python 3.x
- Tkinter (Built-in GUI)
- Math module for time calculation
- Optional: Pygame for sound
