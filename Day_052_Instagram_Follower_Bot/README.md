# Day 52 - Instagram Follower Tracker (Safe Version)

A simple tool to track Instagram growth manually and get growth ideas.

This project DOES NOT auto-follow, auto-like or automate Instagram. It only tracks your followers and suggests growth tips. It is 100% safe for your account.

## Features
- Tracks followers, following and posts daily
- Calculates Follow Ratio
- Gives personalized growth tips based on follower count
- Saves history to `followers.csv`
- No Instagram Login, No Selenium, No API

## Requirements
- Python 3
- No extra library needed
- No Pip Install
