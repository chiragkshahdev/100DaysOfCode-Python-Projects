# Day_007_Hangman_Game

A Classic Hangman word Guessing game - Day 7 of 100  Days of Code.

### 🎮 How to Play
- The Computer picks a random word.
- Guess one Letter at a Time.
- You have 6 Lives. Each wrong guess loses a life.
- Guess the full word before hangman is complete.
