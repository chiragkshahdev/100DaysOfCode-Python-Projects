# Day 23 - Turtle Crossing Game

A Frogger-style game built with Python Turtle module.

## How to Play
- Turtle starts at bottom
- Press UP arrow to move forward
- Avoid cars coming from right to left
- Reach top to go to next level
- Each level cars get faster
- Collision = Game Over

## Concepts Used
- Turtle Graphics
- OOP (Classes: Player, CarManager, Scoreboard)
- Game loop with screen.tracer(0)
- Collision detection with distance()
- Random car generation

## Run
python main.py

## Controls
Up Arrow: Move Turtle
