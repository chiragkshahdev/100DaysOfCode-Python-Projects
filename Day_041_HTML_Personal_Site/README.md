# Day 41 - HTML Personal Site

My first Personal Website using only HTML.

## Features
- Profile Section with Photo and Bio
- Education List
- Work Experience Table
- Skills Table with Stars
- Hobbies Page
- Contact Page with Form

## Files
- index.html - Main Page
- hobbies.html - Hobbies Page
- contact.html - Contact Form

## How to Run
1. Open index.html in any browser
   Double click the file

2. No server needed, no Python needed

## Tech Used
- HTML Only
- Table, List, Form, Image, Links

## What I Learned
- HTML Structure
- Headings, Paragraphs
- Tables
- Forms and Inputs
- Links between pages
