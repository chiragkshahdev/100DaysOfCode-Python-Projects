# 🔐 Day 30 - Password Manager With Search 1

A simple Password Manager built with Python Tkinter.
Generate strong passwords, save them in JSON, and search them anytime.

## ✨ Features
- Generate Strong Random Passwords
- Save Website, Email & Password in `data.json`
- **Search Password** by Website Name
- Error Handling with `try / except / else / finally`
- No External Library Needed - Only Python Standard Library
- Clean Tkinter GUI

## 🚀 How to Run
```bash
cd Day_030_Password_Manager_With_Search_1
python main.py
