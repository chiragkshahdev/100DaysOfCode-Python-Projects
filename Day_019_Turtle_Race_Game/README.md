# Day 19 - Turtle Race Game 🐢

An interactive betting game built with Python Turtle.

### 🎯 What I Learned (CAIO Skills)
- **Object State & Instances:** 6 different turtle objects with same class.
- **User Interaction:** `textinput` - Taking bets like a real product.
- **Game Loop & Race Condition:** `while` loop that powers every game.

### 🎮 How It Works
1. User bets on a color (red, orange, yellow, green, blue, purple).
2. Turtles move randomly (0-10 steps).
3. First turtle to cross x=230 wins.

### 🚀 How to Run
```bash
python main.py
