# Day 43 - CSS Intermediate

TinDog Landing Page - Intermediate CSS Project

## What I Learned - Intermediate CSS
- position: fixed, relative, absolute
- z-index for layering
- display: flex and grid
- :hover, :focus pseudo-classes
- backdrop-filter: blur for glass effect
- transform: translate, scale, rotate
- box-shadow and border-radius
- Media Query for mobile responsive

## Files
- index.html - Structure only
- styles.css - All styling separate
