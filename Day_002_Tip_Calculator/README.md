# Day 2 - Tip Calculator

This is Day 2 Project of 100 Days Of Code In Python.

### Cancept Learned
- Python Data Types (int, float, str)
- Type conversion / Type Casting
- f-strings
- Mathematical Operators
- round() function

### How it Works
1. Takes Total Bill Amount from user.
2. Takes Tip Percentage (10%, 12%, 15%).
3. Takes Number of people to split the Bill.
4. Calculates Total Bill with Tip and splits Equally.
5. Shows final Amount per person with 2 decimal places.
