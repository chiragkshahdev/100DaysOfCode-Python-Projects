# 🔐 Day 029 - Password Manager App

A secure and simple Password Manager built with Python Tkinter.
Generate strong passwords, save them, and search them anytime!

## 📸 Preview
![Password Manager](logo.png)

## ✨ Features
- Generate Strong Random Passwords (Letters + Numbers + Symbols)
- Auto Copy Password to Clipboard
- Save Website, Email & Password in `data.json`
- Search Saved Passwords by Website Name
- Data stored in JSON format - Easy to read
- User-friendly Tkinter GUI

## 🚀 How to Run
```bash
# Install required package
pip install pyperclip

# Go to project folder
cd Day_029_Password_Manager_App

# Run the app
python main.py
