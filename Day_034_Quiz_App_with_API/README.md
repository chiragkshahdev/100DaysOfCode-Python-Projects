# Day 34 - Quiz App with API

A simple Python Quiz App that fetches live questions from an API.

## Features
- Fetches 5 live MCQ questions from Open Trivia DB API
- Random options shuffling
- Score tracking
- Instant feedback for correct / wrong answers

## API Used
https://opentdb.com/api.php?amount=5&type=multiple

## How to Run
1. Install requests:
   pip install requests

2. Run the app:
   python main.py

## Tech Used
- Python
- Requests Library
- Open Trivia DB API
