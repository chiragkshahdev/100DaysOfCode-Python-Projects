# Day 50 - Tinder Auto Swiper (Simulator)

A safe Tinder swipe UI simulator built with Python Tkinter.

This project DOES NOT automate real Tinder. It does not login, does not auto-swipe, and does not violate Tinder's Terms of Service. It is a UI demo to learn swipe logic.

## Features
- Tinder-like card UI
- Like / Pass buttons
- Dummy profiles for demo
- Saves liked profiles to `liked.csv`
- Uses only Python Standard Library

## Requirements
- Python 3
- No extra library needed
- No Selenium, No Pip Install
